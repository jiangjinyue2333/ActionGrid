# ActionGrid 0.4.15

版本 `0.4.15`，版本号 `31`。

0.4.15 针对澎湃 4 任意桌面页的 TalkBack 节点生命周期做了修复：桌面重建节点、连续翻页、返回桌面或切换窗口后，当前页的真实图标和虚拟空格会重新生成，旧页节点和焦点会失效，放置或取消后会把无障碍焦点交还给稳定的目标图标。页码公告继续使用当前页项目数，避免播报回退成总页数。

虚拟网格现在覆盖真实的触摸、连续滑动、双击放置和放置后的节点确认。7748 真机还逐项验收了同页图标前移、后移，第四页文件夹移动到第三页，创建文件夹并移入应用，文件夹内前移和后移，文件夹首成员与末成员移出，以及空文件夹自动消失。系统返回和全局返回都能取消托起并恢复源图标焦点。

## 验证

设备为 Android 17、HyperOS 4，小米桌面 `8.01.02.7748`；使用真实 TalkBack 无障碍树、触摸和滑动输入验证。冷启动后 7 页节点数量为 `13、24、19、15、14、11、18`，焦点分别落在相册、手机管家、DeepSeek、晨光阅读、蚂蚁阿福、UU 跑腿和夸克网盘。正向和反向翻页均播报当前页项目数，例如“第 2 页共 24 项”“第 3 页共 19 项”“第 7 页共 18 项”。

离线回归、Debug 真机探针和原生 ABI 合约检查的完整记录见 [2026-10-25 真机验证记录](DEVICE_VALIDATION_2026-10-25.md) 和 [7748 ABI 证据](LAUNCHER_7748_ABI.md)。8565、7.x 以及未知原生 ABI 仍按现有能力边界处理，未把 7748 的结构证据套用到其他版本。

发布前需要通过项目结构检查、Java/C++ 测试、Lint、Debug/Release 构建、原生策略、原生网格、APK ABI 和正式签名包校验。安装更新后请重启小米桌面，让模块加载新版本。
