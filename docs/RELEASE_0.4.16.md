# ActionGrid 0.4.16

版本 `0.4.16`，版本号 `32`。

本版本修复澎湃 4 文件夹内托起图标返回桌面后的虚拟网格生命周期：返回文件夹时先立即恢复最近一次完整桌面树，第一次返回只关闭文件夹并保留托起源，第二次系统返回或边缘返回手势才取消托起并清除全部虚拟节点。桌面图标托起也统一支持系统返回键和边缘返回手势取消。

底栏现在使用真实物理列计算播报位置。真实底栏图标播报“底栏第 N 个位置”，虚拟底栏空位播报“移至底栏第 N 个位置”。

## 验证

- Android 17 / HyperOS 4 / 小米桌面 `8.01.02.8584` 真机 `192.168.1.36:33043`：文件夹托起、两次返回、桌面图标返回取消、底栏位置播报均通过。
- `scripts/test-native-grid.ps1`：新增文件夹返回、返回键生命周期、桌面快照恢复和底栏位置回归全部通过。
- `scripts/verify-native-probe.ps1`：托起分页、实时占位放置和 Home 进程稳定性通过；`logcat -b crash` 无 `com.miui.home` 崩溃。
- `gradlew.bat test lint assembleRelease`、项目结构、Native ABI、APK ABI 和 7748/8565/8584 离线 launcher contract 检查通过。

安装更新后请重启小米桌面，让模块加载新版本。
