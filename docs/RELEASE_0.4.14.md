# ActionGrid 0.4.14

版本 `0.4.14`，版本号 `30`。

- 修复澎湃 4 冷启动、连续翻页及返回桌面后，自动播报容易回退为总页数的问题。现在使用“第 X 页共 Y 项”，Y 为当前页项目数。
- 修复跨页拖动仍显示上一页空位的问题；满页不产生假空位，跨页时清理旧空位焦点。
- 修复“系统工具”等默认文件夹托起后无法确认来源、无法放置的问题。
- 放置后将读屏焦点交还目标图标；同页取消托起或按返回键取消时恢复原图标焦点。

7748 真机已验证图标和文件夹同页移动、图标跨页往返、放置与取消后的焦点恢复，以及连续 14 次翻页和冷启动播报。测试图标均已还原。Java 123 项、原生回归 67 项通过；完整构建、Lint、原生能力策略及 APK ABI 检查通过。Lint 有 6 条既有警告、零错误。

详细证据与测试方式见 [2026-10-25 真机验证记录](https://github.com/jiangjinyue2333/ActionGrid/blob/v0.4.14/docs/DEVICE_VALIDATION_2026-10-25.md)。7.x 及 8565/7653/7722 未进行本次真机验收；多选、占用位置重排及文件夹内部项目未进行本次设备测试。

安装更新后请重启小米桌面，让模块加载新版本。
