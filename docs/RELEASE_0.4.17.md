# ActionGrid 0.4.17

版本 `0.4.17`，版本号 `33`。

## 修复

- 虚拟空格同时接受原始触摸和 hover 事件。触摸或滑入空格会停止桌面底层触摸流，交由 TalkBack 定位空格；抬指保留双击目标，取消事件清理临时目标。
- 文件夹内托起后返回桌面，继续使用已确认的 favorite ID 和来源容器。之前网格可以出现，但放置时仍错误地拒绝文件夹来源。
- 返回桌面后可直接放入另一个文件夹。已有文件夹成员可能保留旧桌面行号，不再因此拒绝移入；前后插入按实际顺序处理，保留其他成员的相对位置。
- 正常图标与文件夹点击调用系统点按音效接口，遵循“点按提示音”和系统静音设置。无自带音频；原桌面已播放时不重复补播。接口证据见 [SYSTEM_CLICK_SOUND.md](SYSTEM_CLICK_SOUND.md)。
- 调试探针必须确认图标实际到达目标位置，不能仅凭放置动作返回成功就报告通过。

## 真机验收

2026-10-26，`24129PN74C`，Android 17 / HyperOS 4，小米桌面 `8.01.02.8584`，分辨率 `1200×2670`，实际布局 `4×6`，7 页。保留原有 TalkBack 服务配置。测试使用 UHID 多触点输入、实际桌面无障碍动作、桌面节点、数据库保存确认日志及 TTS 合成文本；不是仅在夹具中执行移动算法。

已在真实桌面确认：

- 相册经 TalkBack 右滑选格、手指滑入空格、直接触摸空格后三种方式双击放置，目标为第 5 行第 2 列、第 5 行第 1 列和第 1 行第 2 列，位置、托起状态和焦点均检查。
- 桌面相册在设置前后插入；系统工具内文件管理在笔记前后插入。
- 文件管理从系统工具托起，返回桌面后直接触摸空格或滑动选格并双击放置，再移回系统工具。
- 从系统工具托起后返回桌面，放进读屏文件夹，并在目标图标前后插入后移回；复核未移动成员的相对顺序。
- 系统返回键、无障碍全局返回和真实 UHID“下再左”读屏返回：桌面托起取消；文件夹首次返回保留来源，第二次返回清除托起与虚拟网格。
- 底栏空位触摸、左右滑动的 TTS 合成文本分别为“移至底栏第 1 个位置”和“短信，底栏第 2 个位置”。
- 系统点按提示音开启时，system_server 的 SoundPool 新增一次播放，系统音轨产生播放帧；关闭时两项增量均为零。已恢复用户原有开启状态。

系统边缘返回的 ADB/UHID 输入在当前测试设备上被作为桌面横滑处理，没有产生系统返回事件，不能把它计为边缘返回验收通过；上面的返回键和读屏返回验收与此区分。
