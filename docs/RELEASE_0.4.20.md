# ActionGrid 0.4.20

版本 `0.4.20`，版本号 `36`。

## 更新内容

- 新增小米桌面 8.01.02.9239 适配，支持新版桌面的图标整理、文件夹、小窗和分屏相关操作。
- 适配新版桌面的网格、触摸、焦点和返回流程，沿用原有托起、放置和取消操作。
- 9239 起关闭模块额外的“进入多任务界面”和“系统桌面”播报，包括从应用按主屏幕键、返回键、退出最近任务及快速返回的延迟兜底。仅为已支持的旧版保留补播；新增或未识别的 profile 默认关闭，无需设置开关。任务清除、翻页、托起、放置和取消反馈保持原有行为。
- 保留旧桌面版本支持；未知接口和不匹配的系统库继续关闭未经验证的能力。

## 验证范围

真实安装包与系统库的离线契约核对、123 项 Java 单元测试和 98 项生产 C++ 夹具通过，Lint 无错误，Debug/Release 构建及 APK ABI 检查通过。播报回归覆盖旧版保留补播、9239 关闭补播、快速及连续返回、控制器恢复，以及任务清除反馈保留。

9239 真机已验证模块加载、触摸探索与双击空位放置、7 页翻页、同页/跨页/底栏移动、文件夹移入移出/排序/创建/空夹清理、两级及连续返回键，以及实际小窗和双任务分屏。210 个桌面项目的布局、7 页顺序和原读屏设置已核对恢复。

主屏幕键、返回键、退出最近任务后的桌面动作和无障碍焦点已复查。默认“系统应用”文件夹作为移动锚点、特殊标题“应用详情”任务的小窗请求仍受现有身份校验限制；本机使用三键导航，未验收全面屏边缘返回。详细证据及探针复验边界见 [9239 适配记录](LAUNCHER_9239_ABI.md)。

## 已知原生现象

从 QQ 返回桌面时，在 QQ 内容中移动过焦点通常读一遍“系统桌面”；焦点停在状态栏或底部导航按钮并连续进出时可能读两遍。完全停用模块后，相同焦点条件下也会复现，因此不归为 ActionGrid 缺陷。本版保持原生窗口通知不变，所有临时播报实验均已撤回。

## 在线更新

GitHub Actions 使用原有正式证书签名，并随本版本发布 `ActionGrid-0.4.20.apk` 与 `latest.json`。更新来源选择 GitHub 后，可从“关于与诊断 → 检查更新”获取本版本；版本号从 35 递增到 36，支持旧版识别更新和覆盖安装。

安装更新后重启小米桌面，以加载新版本模块。
