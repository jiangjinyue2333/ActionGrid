# ActionGrid 0.4.19

版本 `0.4.19`，版本号 `35`。

## 更新内容

- “关于与诊断”页新增“隐藏桌面图标”开关，位于源码仓库按钮下方，默认保持显示；确认后关闭 ActionGrid 的桌面和应用抽屉启动入口。
- 隐藏后可从 LSPosed → ActionGrid → 模块设置重新打开并恢复图标，模块功能不受影响。恢复位置由桌面决定。
- 开关状态由系统保存，取消确认不会改变设置；隐藏、取消后恢复无障碍焦点，操作失败时显示实际状态和错误提示。
- 部分系统仍会显示“应用信息”占位图标，小米桌面的完全隐藏效果与真实读屏播报待真机验收。

## 验证范围

123 项 Java 单元测试、Debug/Release 构建、Lint、项目结构、原生能力策略及 APK 安装 ABI 检查通过。

Android 16（API 36）模拟器已验证桌面别名启动、默认显示、确认与取消、系统返回取消、触摸探索模式下的无障碍焦点恢复、隐藏后从模块设置重新打开及恢复显示。另已验证从 0.4.18 覆盖安装后只有一个有效启动入口，以及隐藏状态在覆盖安装、设备重启后保持。

模拟器隐藏后仍返回一个系统占位入口；上述检查不代表小米桌面的实际图标与 TalkBack／解说播报已经完成真机验收。

## 在线更新

GitHub Actions 使用原有正式证书签名，并随本版本发布 `ActionGrid-0.4.19.apk` 与 `latest.json`。应用将更新来源选择为 GitHub 后，可从“关于与诊断 → 检查更新”获取本版本；版本号从 34 递增到 35，支持旧版识别更新和覆盖安装。

安装更新后重启小米桌面，以加载新版本模块。
